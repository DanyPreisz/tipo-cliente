# Clasificación de Tipo de Cliente

Proyecto de clasificación listo para Google Colab. Incluye EDA, modelos y SHAP.

## Abrir en Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/DanyPreisz/tipo-cliente/blob/main/tipo_cliente_colab.ipynb)

- EDA (distribución, boxplots, countplot)

- Modelos: Logistic Regression, Random Forest, Gradient Boosting

- Feature importance
